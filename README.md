# اپ بازی بریمو (لودو ورلد)

بازی لودو بریمو به‌صورت اپ اندروید. کاربر با همان حساب سایت وارد می‌شود (ورود، سکه و سطح از بک‌اند بریمو).

## قبل از هر چیز: بک‌اند
پوشه‌ی `ludo` (`game-api.php`، `ludo-engine.php`، `migration_ludo_game.sql`) را طبق `LUDO_README.md` روی سایت نصب کنید و `api.php` به‌روزشده را جایگزین کنید (فقط لیست origin مجاز CORS عوض شده تا اپ بتواند به سایت وصل شود).

## نسخه‌ی وب (بدون نصب)
فایل `game.html` را کنار `index.html` سایت آپلود کنید؛ بازی در `https://berimoo.com/game.html` باز می‌شود. اگر کاربر در همان مرورگر به سایت وارد شده باشد، خودکار وارد بازی هم می‌شود.

## ساخت APK بدون Android Studio
1. این پوشه را یک repository جدید در GitHub آپلود کنید.
2. تب **Actions** ← «ساخت APK بازی بریمو» ← **Run workflow**.
3. بعد از چند دقیقه، در پایین صفحه‌ی همان اجرا، فایل `berimoo-game-app` (حاوی `app-debug.apk`) را دانلود کنید.
4. APK را روی گوشی نصب کنید (اجازه‌ی نصب از منبع ناشناس را بدهید).

## ⚠️ قبل از تست: بک‌اند باید روی سایت واقعی باشه
این اپ به `https://berimoo.com/game-api.php` وصل می‌شه (نه به یه سرور تست محلی). یعنی قبل از این‌که تاس/حرکت مهره تو اپ کار کنه، باید:
1. فایل‌های پوشه‌ی `ludo` (`game-api.php`, `ludo-engine.php`, `migration_ludo_game.sql`) طبق `LUDO_README.md` روی سایت واقعی نصب شده باشن
2. `api.php` به‌روزشده (با originهای Capacitor مجاز) جایگزین نسخه‌ی قبلی شده باشه

اگه این مرحله هنوز انجام نشده، اپ باز می‌شه و صفحه‌ی خانه رو نشون می‌ده، ولی موقع شروع بازی یا انداختن تاس با خطا مواجه می‌شید — این طبیعیه و ربطی به خودِ اپ نداره.

## نکته‌ها
- این APK «debug» است و برای تست مناسب است. برای انتشار در بازار (کافه‌بازار/مایکت) باید نسخه‌ی release با امضای اختصاصی ساخته شود.
- آیکون اپ فعلاً پیش‌فرض Capacitor است.
- کاراکترها، مهره‌ها و تاس فعلاً گرافیک موقتی (SVG) هستند؛ با ارسال تصاویر نهایی جایگزین می‌شوند.
- دکمه‌ی بازگشت اندروید داخل بازی به‌جای خروج ناگهانی، پنجره‌ی «خروج از بازی» را نشان می‌دهد.
